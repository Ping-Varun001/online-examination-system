**Instructions**
- Install the Requirements: pip install -r requirements.txt
- Then, make database migrations: python manage.py makemigrations
- python manage.py migrate
- And finally, run the application: python manage.py runserver

settings.py is the central configuration file of a Django project.

👉 It tells Django: settings.py
how the project should behave
what apps to load
how to connect to the database
how to handle security, static files, templates, login, etc.
Without settings.py, Django cannot start.
